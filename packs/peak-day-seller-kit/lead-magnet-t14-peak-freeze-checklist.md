## T−14 checklist

1. **One offer** — pick a single peak SKU / discount; hide the rest from the hero.  
2. **Window** — Peak start, Peak end, Timezone (required).  
3. **Delivery** — test that the file actually arrives.  
4. **Code** — create/confirm; test once in incognito (calm verify — no self-scold).  
5. **Sales page** — real dates + timezone; **no** resetting countdown.  
6. **Five macros** — Not delivered · Wrong file · Refund ask · Code fail · Pre-sale.  
7. **Peak board** — triage order + those five only (freeze list stays off peak main screen).  
8. **Status → Frozen**
