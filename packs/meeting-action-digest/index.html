FAQ

Does this join my Zoom/Meet or transcribe calls?

No. You paste notes you already have. Any solid LLM structures them. There is no live bot, plugin, or transcription SaaS in this pack.

Is this a downloadable .notion file?

No — you get clear Markdown property lists and views so you can recreate the system in any Notion workspace without brittle imports.

Which AI do the prompts work with?

ChatGPT, Claude, Grok, or any solid LLM. Variables are marked; example outputs show the bar. Missing inputs → the prompt asks — it shouldn’t invent owners or dues.

Is this a project-management tool?

No. It’s an owner-chase loop for meeting follow-ups — not a Jira/Linear/Asana clone and not an OKR framework.
