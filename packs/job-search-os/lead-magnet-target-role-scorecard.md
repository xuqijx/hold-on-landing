## 7 scoring mistakes that kill interviews

1. **Scoring after you already Easy Applied.** → Score first.  
2. **Counting “interested” as evidence.** → Evidence is work you did.  
3. **Inflating Partial into Yes.** → Partial stays Partial; tailor carefully or Skip.  
4. **Inventing % lifts for the bullet rewrite.** → ASK yourself for real numbers or write qualitative bullets.  
5. **Keyword stuffing the JD.** → ATS black-hat and spam get refused in the full kit — don’t practice them here.  
6. **Keeping 40 active targets.** → Cap ≈5–15 focused roles.  
7. **Treating Weak fits as “manifesting.”** → Skip is a win (saved time).

## 15-minute first-win outline

1. **0–2 min:** Pick one real JD; open a Target note.

4. **15 min:** Stop. Apply in a separate block if Strong/Maybe.
